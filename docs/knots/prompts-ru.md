# Готовые промпты на русском

По одному узлу за раз: приложить образец из `reference-samples/`,
вставить промпт целиком. Общая часть уже включена в каждый промпт —
ничего дописывать не нужно.

Спецификация вязки и критерии приёмки — в файлах `01`…`07`.

| узел | что прикладывать |
|---|---|
| беседочный | `lj-01-bowline.jpg` |
| восьмёрка | образца нет, промпт самодостаточный |
| прямой | образца нет, промпт самодостаточный |
| выбленочный | `lj-02-clove-hitch.jpg` |
| штык со шлагом | `lj-04-two-half-hitches.jpg` |
| шкотовый | `lj-05-sheet-bend.jpg` |
| задвижной штык | `lj-06-rolling-hitch.jpg` |

## 1. Беседочный · bowline

```
На приложенной картинке — образец геометрии узла. Возьми из неё только
траекторию троса: какая прядь проходит поверх какой. Композицию, позу
и пропорции не повторяй, нарисуй заново.

Нарисуй беседочный узел (булинь). На коренной части небольшая колышка.
Ходовой конец входит в колышку снизу вверх, обносит коренную часть сзади
— образуется воротник, видимый отдельной дугой, — и возвращается
в колышку сверху вниз, рядом с той прядью, по которой вошёл. Снизу
остаётся незатягивающаяся петля.

Важно: в обеих половинах кадра ходовой конец выходит ВНУТРИ петли,
не снаружи и не вверх.

Композиция: два вида одного и того же готового узла рядом, в одном
масштабе, без разделительной линии. Слева узел уложен свободно, все
пересечения разнесены и читаются. Справа тот же узел затянут, как
выглядит в работе.

Стиль: редакционная штриховая иллюстрация для карманного справочника.
Уверенный чёрный контур, плоские серые заливки. Без штриховки, без
гравюрной фактуры, без градиентов, без объёма и теней. Строго монохром:
чёрный и нейтральные серые, никакого цвета. Фон чисто белый, пустой.
В кадре нет рук, предметов, подписей, букв и цифр.

Трос круглый, витой. Коренная часть светло-серая, ходовой конец заметно
темнее — чтобы путь троса читался с одного взгляда. На каждом пересечении
верхняя прядь непрерывна, нижняя ею прервана.

Кадр плотный: сам узел занимает большую часть высоты, петля укорочена
и не больше половины кадра. Свободный конец короткий, около четырёх
диаметров троса.
```

```
Нарисуй прямой узел, он же рифовый в английской традиции reef knot,
```

## Что проверять в присланном

1. **Тон.** Две пряди разного серого. Если обе белые — путь троса
   не читается, брак независимо от геометрии.
2. **Критерий узла** из файла `01`…`07`. Для булиня — конец внутри петли
   в обеих половинах. Для прямого — концы каждой верёвки с одной стороны.
   Для шкотового — свободные концы с одной стороны.
3. **Кадр.** Узел занимает большую часть высоты. На странице ячейка
   54,5 мм на две половины — по 25 мм на узел, лишнее поле съедает
   читаемость.
4. **Самостоятельность.** Поза и пропорции не повторяют образец.
5. **Завязать по картинке.** Если по левой половине узел не вяжется или
   получается другой — рисунок не годится.
