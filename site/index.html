Собрать самому

Книга пересобирается из исходников

Бинарного макета нет: вёрстка описана кодом на Python через reportlab. Правится текст — пересобирается книга.

git clone https://github.com/yknnv/sail-logbook.git
cd sail-logbook
pip install -r requirements.txt
./build.sh

build.sh собирает три PDF и прогоняет проверку вёрстки: выход за границы набора с допуском 0,15 мм, горизонтальные наложения символов, вертикальные наложения слов. Переполнение страницы роняет сборку с указанием страницы и недостающих миллиметров — молча съехать вёрстка не может.

Число разворотов под записи, диаметр и шаг отверстий, поля и версия задаются константами в начале src/logbook.py.

Вопросы

На какой бумаге печатать?

Офсет 100–120 г/м², двусторонняя печать в одну краску. Тоньше 90 г/м² текст просвечивает, толще 130 г/м² пачка перестаёт складываться в кольцах.

Почему нет номеров страниц?

Листы съёмные, порядок задаёт владелец: отработанные переходы вынимаются, нужные справочные страницы переставляются вперёд. Напечатанный номер такому порядку мешал бы.

Подойдёт ли перфорация к моей папке?

Расположение колец у папок разное, поэтому сначала печатается шаблон перфорации в масштабе 100 % и прикладывается к обложке. Диаметр, отступ от края и шаг отверстий — константы HOLE_D, HOLE_INSET, HOLE_SPACING.

Можно ли добавить свои страницы?

Да. Каждая справочная страница — одна функция в src/reference.py, порядок задаёт список pages. Правила вёрстки описаны в CONTRIBUTING.md.

Журнал бесплатный?

Да. Код — MIT, содержимое — CC BY-NC-SA 4.0: печатайте для себя, экипажа или школы, но не на продажу.

Заменяет ли справочник обучение?

Нет. Числовые ориентиры и процедуры зависят от подготовки, снаряжения, местных правил и плана перехода. Журнал — памятка для того, кто уже учился.
